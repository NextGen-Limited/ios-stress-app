Stress calculation, end to end

How iPhone and Apple Watch health signals become a personalized 0–100 stress result, a confidence score, a per-factor explanation, and durable history.

01 · System view

High-level calculation architecture

The foreground path uses the five-factor engine. A separate background refresh path still calls the legacy HRV + heart-rate calculator.

02 · Algorithm view

Foreground workflow and decision points

Critical HRV is required by the view model. Secondary inputs degrade gracefully; the calculator skips unavailable factors and redistributes their weight across the factors that returned a score.

Composite and confidence

level = clamp(Σ(value × normalizedWeight) × 100). Completeness is the available weight divided by total configured weight. Confidence is 40% completeness + 60% mean factor confidence.

Category boundaries

Relaxed <25, Mild <50, Moderate <75, High <90, Severe ≥90. UI dual-codes each category with color, icon, text, and pattern.

Implementation caveats

  • The foreground calculator is constructed before the baseline is loaded, so persisted calibrated weights are not currently injected into its stored weight set.
  • Background refresh calls the legacy two-factor API.
  • Watch measurement builds a default baseline instead of loading the phone’s personalized baseline.

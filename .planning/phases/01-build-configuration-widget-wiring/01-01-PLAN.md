## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App process ↔ widget/watch extension process (via App Group UserDefaults) | Any app/extension co-signed into the same App Group can read the shared suite — an OS-level boundary, not a code-level one |
| Compiled bundle ↔ App Store Connect validator | Privacy Manifest declarations are the artifact ASC's automated pipeline and human reviewers inspect |

<objective>
Make "delete" actually delete everywhere the UI claims it does, protect health-data exports at rest and in transit, and collapse the duplicate data-management stack so exactly one canonical delete path remains — the existing-but-unreferenced `DataDeleterService`.

Purpose: The UI promises "Removes every locally stored measurement" (Delete All) and "wipes all data, character unlocks, and preferences" (Factory Reset), but `performDeleteAll` only clears SwiftData + CloudKit, leaving the Keychain JWT and the App Group widget cache behind — so a "deleted" user is still signed in and the widget still shows their stress score. Separately, exports have no size cap and their temp files survive until a 1-hour sweep, and two dead plaintext-mapping CloudKit structs are a latent encryption-bypass risk. This plan closes all five gaps in one coarse vertical slice.

Output: An extended `DataDeleterService` that clears credentials + shared caches, retargeted delete views, hardened exports, deleted dead code, and a new test bundle proving the gap is closed.
</objective>

### Task 8: ASC Privacy Questionnaire (SHIP-03) — DEFERRED

<task type="checkpoint:human-verify" id="privacy-questionnaire" gate="blocking">
<name>Answer ASC privacy questionnaire consistent with D3</name>
<requirements>[SHIP-03]</requirements>
<what-built>
The privacy questionnaire must be answered in App Store Connect, consistent
with the Phase 1 D3 resolution: privacy manifest completed, chat content

3. Declared data types: Contact Info (email via Apple Sign-In), Usage Data (chat coaching context), Identifiers (user ID for backend auth)
4. Confirm no HealthKit data is declared as collected — it never leaves the device
5. Save and submit for review alongside the app
</how-to-verify>

<objective>
Build the backend half of purchased-credit grants: POST /credits/redeem verifying an Apple StoreKit 2 signed transaction (JWS), granting credits exactly once per transaction, atomically, to the authenticated user.

Purpose: Research verified the backend can deduct and report credits but cannot grant purchased ones — the credit_type 'purchase' enum exists with no route behind it. Without this endpoint, iOS purchases would have no server-side destination, i.e. a fake implementation (research "Critical Backend Gap"). This is the only genuinely new server-side surface in the phase.
Output: Deployable (not yet deployed — deployment is 02-04 user_setup) redemption route with unit coverage, plus a migration.
</objective>

<objective>
Make the home-screen widget's rendering match reality: prove the App-Group publish/subscribe key
contract with a regression test, replace the conflated isPlaceholder boolean with an explicit
fresh/stale/empty state resolver (unit-tested), and update the three widget views to render stale
and truly-empty data per 01-UI-SPEC.md's Widget State Contract.

Purpose: 01-RESEARCH.md's Assumption A3 and 01-UI-SPEC.md both flag that today's
`isPlaceholder: latestStress == nil || isStale` computation makes true "never measured" data
unreachable — it always falls to the generic placeholder with fabricated sample numbers instead of
an honest "No Data" message. This plan closes that gap and adds the stale-data dimming/labeling
01-UI-SPEC.md specifies.

Output: a tested `WidgetDataState` resolver, a tested `WidgetPublisher`/`WidgetDataProvider` key
contract, and three widget views that correctly distinguish fresh, stale, and empty data.
</objective>
